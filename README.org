Este repositorio contiene el código fuente y la infraestructura de mi portafolio profesional y currículum vitae. 
El sitio está construido con una filosofía minimalista: texto plano, cero dependencias de JavaScript en el cliente y generación estática pura mediante =Org-mode= y =Emacs=.

* Estructura del Proyecto

El contenido está separado de la infraestructura técnica:

- [[./index.org][index.org]] :: Contenido fuente (currículum, contacto y proyectos). *Edita este archivo para actualizar la web.*
- =style.css= :: Hoja de estilos (generada automáticamente desde este README).
- =.github/workflows/deploy.yml= :: Pipeline de despliegue (generado automáticamente desde este README).

* Infraestructura y Estilos (Literate Programming)

Los siguientes bloques definen la configuración técnica del proyecto. Para extraerlos a sus respectivos archivos, abre este documento en Emacs y ejecuta =M-x org-babel-tangle= (=C-c C-v t=).

** Pipeline de CI/CD (GitHub Actions)
Este flujo de trabajo instala Emacs en un contenedor de Ubuntu, compila =index.org= a HTML y lo publica en GitHub Pages cada vez que se hace push a la rama =main=.

#+begin_src yaml-ts :tangle .github/workflows/deploy.yml
name: Desplegar Portafolio a GitHub Pages

on:
  push:
    branches:
      - main

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Descargar repositorio
        uses: actions/checkout@v4

      - name: Instalar Emacs
        run: sudo apt-get update && sudo apt-get install -y emacs-nox

      - name: Compilar Org a HTML
        run: |
          emacs index.org --batch -f org-html-export-to-html --kill
          mkdir -p dist
          mv index.html style.css dist/

      - name: Subir artefacto de Pages
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Desplegar a GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
#+end_src
